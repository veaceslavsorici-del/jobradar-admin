# jobradar-admin

Веб-админка бота JobRadar (@Work_Radar_MD_Bot). Открывается только из бота кнопкой «🖥 Админка» в /admin (Telegram Mini App).
Вход проверяет сам бот по подписи Telegram; пускает только владельца. Страница только показывает числа — без имён, телефонов и текстов; из вакансий — только название, компания и город одобренных (их и так видят все в группе).

Секретов здесь нет. Контракт ответа — `docs/ADMIN_WEB_SPEC.md` в хранилище бота.

- `index.html`, `app.v1.js` — страница (вывод только через `textContent`, ничего не хранится на устройстве).
- `admin.v1.css` — стили (TailAdmin, MIT; см. `tailadmin/SOURCE.md`).
- `check.ts` — проверка перед публикацией (запрещённые приёмы, чужие адреса, CSP).
- `answer.html`, `answer.v1.js`, `answer.v1.css` — страница ответа компании кандидату (кнопки в письме-отклике, v713 бота): одна кнопка подтверждения, ответ — POST `?answer` функции бота; значения из адреса на страницу не выводятся.
